# AI assistance and direct contributions

ChatGPT/Codex generated and revised portions of the Python backend, JavaScript interface, GIS-processing scripts, repair tools, documentation, and submission materials. Generated branding images also used OpenAI image generation. Google Gemini powers the in-app assistant and receives selected app results and methods context.

The developer's direct contributions included the project concept, feature and interface decisions, local scope and dataset selection, QGIS preparation and visual checks, focus-area drawing, candidate review, repeated local tests, reporting failures, specifying corrections, and deciding which outputs to retain or reject. This is an AI-assisted implementation; it is not a claim that every line was independently written by the student.

Gemini explanations do not independently verify a planting site or inspect private QGIS files. AI-produced changes and analysis require review. Future urban-forestry partnerships are proposals, not established collaborations.
